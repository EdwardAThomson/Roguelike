# Roadmap

Modern Rogue Classic is a frozen edition of Modern Rogue at version 0.6.0 "Torchlight", with the Classic and ASCII display styles. It gets occasional bug fixes but no new features. Bug reports are welcome as issues.

New features (16-bit graphics with lighting, the Descent campaign, the town hub, bosses and more) go into Below Emberwick, the commercial successor, which is developed separately.

The history of this edition is in [`DEVLOG.md`](DEVLOG.md) and [`documentation/CHANGELOG.md`](documentation/CHANGELOG.md).
